## Guidelines for Adding Documents

1. **Include context** - What project/task led to these learnings?
2. **Document errors encountered** - What went wrong and why?
3. **Provide solutions** - What fixed the problem?
4. **Add verification steps** - How to confirm the solution works?
5. **Date everything** - When was this learned/validated?
